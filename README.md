# Smart Placement Tracker
CareerTrack Pro is a modern placement tracking web application that helps students manage job applications, monitor interview progress, track application status, and organize placement activities efficiently. Built using HTML, CSS, and JavaScript with local storage support.

## Features
- Add/Delete company applications
- Track status: Applied → Interview → Selected/Rejected  
- Live counters for each status
- Search and filter companies
- Data saved in browser LocalStorage
- Dark theme with hover glow effects
